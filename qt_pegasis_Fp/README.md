# qt-Pegasis-Fp

This repository contains a C and Python/SageMath implementation of qt-Pagasis over $$\mathbb{F}_p$$ with the new 4-dimensional isogeny formulae introduced in our paper (Dartois and Duparc, 2026).

We refer to the `README.md` files of `Sage_Code` and `C_Code` folders for further instructions on how to run the code.
